# Controle de Cartão de Crédito

Projeto inicial para desenvolvimento de um sistema de controle de cartões de crédito.

## Estrutura
- `index.html`: página principal.
- `css/style.css`: estilos da aplicação.
- `js/script.js`: lógica JavaScript.

## Como executar
Abra o arquivo `index.html` no navegador ou publique o repositório com GitHub Pages.

## Desenvolvimento
Este repositório contém apenas a estrutura inicial. As funcionalidades do sistema serão adicionadas posteriormente.
